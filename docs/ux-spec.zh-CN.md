# Folder Nodes 交互规范

## 设置

设置分为“常规”和“选区与命名”两个选项卡，使用 Obsidian 原生控件、主题变量、键盘焦点与 44px 触摸目标。

## 创建与选区

创建前预览最终名称。aliases 只取选中文字；前缀、后缀和连接符只影响文件夹与文件 basename。

## 迁移与健康

迁移是独立预览流程，不是第三个设置页。健康扫描汇总叶子 Markdown、缺失节点笔记和阻塞冲突。

## 大目录

内容视图渐进显示，每批最多 200 项。一次常规拖动只改移动节点；局部重排窗口最多 64 个节点。
