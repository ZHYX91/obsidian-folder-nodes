# Folder Nodes

Folder Nodes 将受管 Vault 中的每个文件夹表示为同名节点笔记：`A/A.md`。

## 界面截图

首个公开候选版本完成 Obsidian 验收后补充截图。

## 功能特性

- 创建、重命名、移动、排序和安全删除完整 Folder Node。
- 从选中文字创建节点：`aliases` 保持选中文字原文，文件名支持前缀、后缀、连接符和时间戳。
- 迁移始终先预览，再显式提交。
- 自然排序不写元数据；手动排序使用子节点自己的稀疏 `folderNodeOrder`。
- 不生成永久 ID，不写 `_pkwf`。

## 使用要求与兼容性

Obsidian Desktop 1.12.7 或更高版本。0.1.0 暂定仅桌面端。

## 安装

开发安装运行 `npm ci` 和 `npm run build`，将 `dist` 中三个运行文件复制到 `.obsidian/plugins/folder-nodes/`。

## 使用

已有 Vault 先打开迁移预览并确认。空 Vault 或已经满足结构的 Vault 可直接初始化。节点操作可从命令面板和文件夹右键菜单进入。

## 设置

“常规”包含接管状态、模板和图标继承；“选区与命名”包含 aliases、前后缀、连接符和时间戳。

## 限制

节点身份是当前路径而不是稳定 ID。外部“删除后新建”不会被猜测为重命名。文件资源管理器增强属于兼容边界。

## 隐私与安全

插件只在本地工作，不发起网络请求。迁移遇到冲突会阻止提交，不覆盖已有目标。

## 开发

使用 Node 24.18.0 与 npm 11.16.0；提交前运行 `npm run check`。

## 支持
