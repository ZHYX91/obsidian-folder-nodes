## الميزات

يجمع Folder Nodes بين مجلد في Obsidian وملاحظة Markdown تحمل الاسم نفسه. مثلًا، يشكّل المجلد A والملف A/A.md عقدة مكتملة. إذا غاب أحدهما فستظهر حالة «غير مكتملة»، ولن ينشئ الملحق الملفات أو ينقلها من تلقاء نفسه.

ستستمر في استخدام مستكشف الملفات الأصلي في Obsidian، مع إضافة شريط جانبي لمحتويات العقد وNode Graph لعرض العلاقات وأيقونات مخصصة وترتيب يدوي للعقد المتجاورة.

يمكنك إنشاء العقدة المكتملة أو إعادة تسميتها أو نقلها أو دمجها أو ترتيبها أو حذفها. يبقى مستكشف الملفات الأصلي في Obsidian كما هو. تعرض محتويات العقد العقد الفرعية وألبوم الصور الثابتة والملفات الأخرى في أقسام منفصلة. تظهر ملفات GIF بصور مصغرة ثابتة، ولا يوجد تشغيل فيديو أو صوت مضمّن. يحافظ Node Graph على شجرة المجلدات ويمكنه إظهار الروابط بين الملاحظات بشكل إضافي.

## المتطلبات والتوافق

يتطلب الملحق Obsidian 1.12.7 أو أحدث.

يدعم الملحق إصدار سطح المكتب وAndroid. على Android تُنقل المجلدات من خلال القوائم. لم يُتحقق بعد من التوافق مع iOS.

## التثبيت

افتح «الإعدادات ← الإضافات المجتمعية ← تصفح»، وابحث عن Folder Nodes ثم ثبّته وفعّله. إذا لم يظهر في الدليل، نزّل `folder-nodes-<version>.zip` من [Releases](https://github.com/ZHYX91/obsidian-folder-nodes/releases) واستخرج مجلد `folder-nodes` إلى `Vault/.obsidian/plugins/`. يحتوي ZIP على مجلد الإضافة أصلًا، فلا تستخرجه داخل `plugins/folder-nodes/`.

يمكنك أيضًا وضع ملفات `main.js` و`manifest.json` و`styles.css` من الإصدار نفسه مباشرة في `Vault/.obsidian/plugins/folder-nodes/`. أعد تحميل Obsidian وفعّل الإضافة، ولا تخلط ملفات إصدارات مختلفة. احتفظ بملف `data.json` عند التحديث للحفاظ على التفضيلات وقواعد الاستثناء.

## الاستخدام

1. أنشئ نسخة احتياطية من خزنتك، ثم راجع قسمي «عام» و«الإدارة» في إعدادات Folder Nodes.
2. تأكد من وجود الملاحظة A/A.md داخل المجلد A. إذا كانت هناك قطعة مفقودة، يمكنك إنشاؤها بنفسك أو استثناء العنصر من الإدارة.
3. اختر «عقدة جديدة» لإنشاء المجلد والملاحظة معًا. اضغط اسم المجلد لفتح ملاحظة العقدة. يتيح لك «محتويات العقدة» تصفح العقد الفرعية والصور والفيديو والملفات الأخرى.
4. افتح Node Graph. يعرض «كامل المخطط» جميع العقد المُدارة، و«الشجرة الفرعية» العقدة المحددة ونسلها، و«المنطقة المحيطة» سياقها القريب. يمكنك التبديل بين 2D و3D وإظهار الروابط بين الملاحظات.

عند إنشاء عقدة من نص محدد، يمكنك مراجعة الاسم والمكان والأسماء البديلة. يمكن أيضًا إنشاء عقد من روابط داخلية لم تُنشأ بعد ضمن النطاق المُدار. يرفض الملحق تحديد نص يمتد عبر عدة خلايا من جدول Markdown لحماية الجدول من التلف.

تعرض محتويات العقدة المسار الحالي وتوضح سبب الحالة الفارغة أو المخفية أو غير المُدارة أو غير المكتملة. تتيح الأزرار المتاحة فتح عقدة أصل صالحة أو قواعد الإدارة أو الفحص للقراءة فقط، أو إظهار العقد المخفية خلال الجلسة. في مخطط Canvas تنتقل مفاتيح الأسهم إلى أقرب عقدة في ذلك الاتجاه على الشاشة؛ ويختار Home وEnd أول عقدة ظاهرة وآخرها.

إذا فشلت العملية بعد إنشاء ملاحظة، فلا يحذف التنظيف إلا الملفات التي ما زال يمكن التأكد من أنها تخص العملية ولم تتغير. تُحفظ الملاحظات المفتوحة أو المعدّلة. يذكر الخطأ المسارات المتبقية والسبب: احفظ هذه الملفات وراجعها قبل اتخاذ قرار بحذفها يدويًا.

## الإعدادات

**عام**: لغة الواجهة والعقد المخفية والصفحة الرئيسية. **الإدارة**: قواعد الاستثناء والتنظيم الجماعي وترحيل الخصائص والفحص للقراءة فقط. **الأيقونات والمظهر**: الوراثة والموضع وخط الإيموجي. **التحديد والتسمية**: التأكيد والأسماء البديلة وقواعد التسمية. **Node Graph**: الأبعاد والاتجاه وأداء الرسوم الكبيرة. تغيير اللغة لا يعدّل الملاحظات.

## خاصية folder-nodes

```yaml
folder-nodes:
  - order=manual
  - rank=1024
  - hidden=true
```

تحتفظ قائمة النصوص `folder-nodes` في ملاحظة العقدة بالإعدادات غير الافتراضية فقط: يفعّل `order=manual` الترتيب اليدوي للعقد الفرعية، ويحفظ `rank=N` ترتيبها، بينما يخفي `hidden=true` العقدة ونسلها المُدار. لا تُكتب القيم الافتراضية وتُحذف الخاصية إذا أصبحت القائمة فارغة. ما زالت الحقول القديمة `folderNodeChildrenSort` و`folderNodeSiblingRank` و`folderNodeHidden` قابلة للقراءة. لا تتم الترقية تلقائيًا عند التشغيل. حدّث الملحق على جميع الأجهزة، ثم راجع المعاينة في «الإدارة» قبل الموافقة.

## خاصية icon

تقبل خاصية icon في ملاحظة العقدة صور الخزنة وأيقونات Lucide والحروف المفردة والرموز التعبيرية حسب ترتيب الأولوية. يُستخدم color: لتلوين الحروف وأيقونات Lucide أو كلون بديل. تتوفر معاينة في الإعدادات.

```yaml
icon:
  - "[[Assets/project.svg]]"
  - "lucide:folder-tree"
  - 文
  - "color:#7c3aed"
```

## القيود

**قبل دمج العقد:** احفظ ملاحظتي العقدة المصدر والهدف وكل ملاحظات Markdown التي ستُنقل، ثم أغلق علامات تبويب تحريرها. يفحص الدمج الروابط النسبية المدعومة مثل `../Reference.md` قبل الكتابة، ويرفض العملية إذا تغيرت الوجهة أو تعذر فحص الصيغة بأمان، بما في ذلك تعريفات الروابط النسبية ذات الوجهة في السطر التالي. لا يعيد كتابة الروابط تلقائيًا. عالج الروابط المشار إليها قبل المحاولة مجددًا، واحتفظ بنسخة قابلة للاستعادة من الملاحظات المهمة وافحص الروابط والمرفقات بعد النجاح.

تُحدد هوية العقدة بمسارها الحالي في الخزنة وليس بمعرّف دائم. لا يمكن استبدال A/A.md بأسماء README.md أو index.md أو _A.md. يتوقف الدمج عند تعارض المسار أو frontmatter. لا يدعم الملحق الصور البعيدة أو إنشاء صور مصغرة لملفات PDF/الفيديو أو معاينة HEIC/HEIF أو تشغيل الوسائط داخليًا. لا تتوفر طريقة السحب والإفلات المكتبية على Android. تتحول الرسوم الكبيرة إلى Canvas مع بقاء التسلسل الهرمي كاملًا.

## الخصوصية والأمان

**الإخفاء**: تؤدي العلامة hidden=true في الخاصية folder-nodes إلى إخفاء العقدة ونسلها في عروض Folder Nodes فقط: مستكشف الملفات ومحتويات العقد وNode Graph. يبقى البحث في Obsidian وفتح الملفات مباشرة متاحين. **غير مُدار**: لن يغيّر Folder Nodes بنية هذه الملفات والمجلدات، لكنه لا يخفيها ولا يحذفها.

تؤثر عمليتا النقل والحذف العاديتان في الملف أو المجلد المحدد. أما إعادة تسمية مجلد العقدة المكتملة أو ملاحظتها التي تحمل الاسم نفسه فتزامن اسم الجزء الآخر أيضًا عند عدم وجود تعارض. أوامر «العقدة التي تحتوي الملاحظة» تستهدف العقدة كاملة. تعرض عمليات التنظيم الجماعي وترحيل الخصائص معاينة قبل الكتابة، وفحص الحالة للقراءة فقط. عند وجود تعارض يتوقف الملحق بدل التخمين. يتبع حذف العقد المكتملة طريقة حذف الملفات المحددة في إعدادات Obsidian.

تتم المعالجة محليًا دون رفع الملاحظات أو إرسال طلبات شبكة. تُكتب الروابط في الحافظة فقط إذا اخترت النسخ صراحةً، ولا يقرأ الملحق الحافظة أبدًا. تُحفظ الإعدادات وقواعد الاستثناء في data.json.

## التطوير

للتطوير استخدم Node.js 24.19.0 وnpm 11.17.0، وشغّل `npm ci` و`npm run check` و`npm run release:check`. تتوفر المستندات التقنية التفصيلية بالإنجليزية والصينية المبسطة.

```bash
npm ci
npm run check
npm run release:check
```
