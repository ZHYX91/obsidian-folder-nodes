# Folder Nodes — Testing strategy

## Automated gates

`npm run check` pins Node/npm, then runs lint, formatting, bilingual-document contracts, strict TypeScript, coverage, production bundle, and release-layout checks. Core, Settings, critical structural adapters, and the production Node Graph entry/state/index/renderer path use thresholds of statements 80%, lines 80%, functions 75%, and branches 70%; existing thresholds are not lowered to admit the graph. Tests cover paths plus Windows reserved names and grapheme-safe truncation, selection naming, safe table-cell aliases, cross-cell rejection, unresolved-link target and display-alias planning, Visuals, malformed frontmatter boundaries, non-Markdown bulk-organization collisions, exact-path/name-start unmanaged rules, protected system folders, deep settings normalization, curated Emoji-font validation and fallback stacks, the property contract, sparse ordering, and incremental reverse references. NodeService uses an in-memory Vault/FileManager behavior fixture covering serialized creates, transactional explicit-path Node creation and rollback, link-safe rename/move, target-rank reconciliation after native cross-parent moves, note-only move/delete, synchronized folder/canonical-note rename, folder-side and Markdown-side incomplete nodes, continuous classification without initialization, ignored-subtree moves, bulk-organization TOCTOU and post-commit validation, merge conflicts, rollbacks, and lifecycle abort after an in-flight write. Synchronous and asynchronous scanners must produce equivalent plans, and cancellation must perform no write. VaultOperationCoordinator tests lock serialization after failure, recursive event attribution, and TTL. UI/runtime tests lock Explorer-surface start/stop cleanup, no mobile draggable ownership, retained native create controls plus New node, incomplete/unmanaged/conflict states, note-title icons outside editable title text, measured title-icon alignment, visual-kind font classes, local Emoji-font detection failures, cross-document runtime font updates, disclosure selectors, before/into/after zones, drag payload, Shift+F10/Menu keys, and the settings hierarchy/explanation cards; source architecture contracts prohibit a global body observer, `vault.rename`, and Contents-wide `resolvedLinks` scans.

Node Graph tests import the real production entry and exercise registration, enable/disable, leaf reuse/close, state migration, and teardown rather than relying on source-string assertions. Pure behavior fixtures cover all three progressive defaults, root/local boundaries, multiple simultaneous branches, direct/Alt/range expansion, collapse to level 1, session-only expansion, old relation migration, search snapshot restoration, external focus, node-body open/menu behavior, Tooltip/keyboard/ARIA, Visual fallback, left-to-right/top-to-bottom structure anchors, independent link anchors, structure edges surviving link LOD, and one RuntimeStyles authority. Narrow-screen, coarse-pointer, and synthetic touch coverage protects Android-compatible code without being represented as real Android host evidence.

Regressions additionally inject a concurrent closed-file edit, an unsaved open editor, a same-path TFile replacement, and a same-path folder replacement during rollback. Settings-save tests delay and fail earlier persistence calls to prove snapshot isolation, ordering, and recovery of the queued latest state.

## Performance

The quick gate covers 10,000 and the large gate 100,000 direct Child Nodes; a normal reorder plan must finish within two seconds and create one property patch. Local rebalance for crowded ranks is bounded to 64 nodes. The reverse-reference benchmark builds quick 20,000/large 100,000-source indexes and applies 1,000 incremental removals. The incomplete-node scan checks near-linear planning and exact counts for quick 20,000/large 100,000 entries. RefreshScheduler tests combine 10,000 requests into one batch. In one deterministic serial worker, the Node Graph benchmark builds the real production GraphIndex for quick 20,000/large 100,000-node fixtures, then applies 32/128 non-nested dirty roots in one incremental refresh. Quick initial build and refresh each have a 2-second threshold; their large equivalents each have a 6-second threshold. Search-candidate aggregation plus an exact query has 1-second quick and 3-second large thresholds. The same refreshed snapshot is fully expanded through topology, VisibleScene, model aggregation, and 2D layout, with 4-second quick and 6-second large thresholds; pure 3D layout plus one 1920×1080 projection has 2-second quick and 5-second large thresholds. These deterministic computation gates expose linear regressions but do not prove interactive Canvas frame rate or host UI responsiveness. Separate GraphIndex behavior tests lock one initial inventory, path-targeted subtree refresh, sibling order, link-only invalidation, and exact scan counters. Those counters prove that scope, search, expansion, dimension, and **Show links** do not repeat a Vault-wide inventory. Full expansion keeps DOM node counts constant, preserves all visible structure edges, and applies the configured limit only to link edges. Contents View paginates Nodes, Album, and Files independently at 200 entries per batch. Album images draw once from resource URIs to canvas, and ordinary files do not read binary bodies.

## Themes and accessibility

Check at least default light, default dark, and one third-party theme. Keyboard checks cover all five settings tabs, modal buttons, Contents cards/rows, More actions, context-menu keys, breadcrumbs, and the Node Graph visual/body/child-handle controls. Drag has equivalent menu move/reorder actions, and coarse-pointer targets are 44px. English and Chinese must not truncate critical buttons or node titles. Follow Obsidian must match Obsidian's current interface language. Images use empty decorative alt text or filename alt text. The Root row is checked for one idempotent insertion, no disclosure control, keyboard activation, and active state. Explorer and title icons are checked for Incomplete node, Unmanaged, and Conflict badge contrast, glyph/CJK/emoji font fallback, size, vertical and horizontal alignment, and name spacing at multiple UI scales. Node Graph additionally checks tooltips, visible focus, explicit accessible names, dashed-link contrast, left-to-right/top-to-bottom handle rotation, and toolbar wrapping without covering the graph.

## Android mobile acceptance

Every `isDesktopOnly: false` candidate must retain Android-compatible code and CSS, with automated narrow-screen, coarse-pointer, and touch coverage. For the Node Graph repository/desktop candidate handoff, a real Android host run is not a blocking gate; when it is not performed, the evidence must say **not covered**, never passed. A separately authorized mobile run may use the current Android 15/API 35 emulator and a disposable Vault to cover plugin load, File Explorer/Contents, native moves, menus, settings persistence, Node Graph scopes/handles/search/2D/3D, narrow layout, touch targets, system trash, and disable cleanup. Emulator evidence is not physical-device or iOS evidence, and no iOS result is claimed by this workflow.

## Production deployment

A production Vault requires explicit authorization for its exact path. Confirm Obsidian is stopped, preserve `data.json`, replace only `main.js`, `manifest.json`, and `styles.css`, and compute SHA-256 for candidate and deployed files. Production deployment is not acceptance; the user's manual acceptance result is recorded separately.
